## 為什麼自己架站

之前考慮過 Blogger、Medium、方格子等平台，最後選了 **Hugo + GitHub Pages**，
主要因為：

1. **內容是我的**：所有文章是 Markdown 檔案，放在我自己的 git repo 裡。
   哪天平台收掉、改規則，我都不受影響。
2. **圖片跟文章綁在一起**：用 Hugo 的 Page Bundle，一篇文章 = 一個資料夾，
   圖片放在資料夾裡。不會有「圖片池」越長越大、不知道誰用了誰的問題。
3. **完全免費**：GitHub Pages 對公開 repo 免費託管，自訂網域也免費。
4. **工程師友好**：寫 Markdown、git push 就上線，跟寫程式同一套工作流。
